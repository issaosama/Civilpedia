# دليل إعداد Google Sheets لمحتوى Civilpedia

## لماذا Google Sheets؟

تتيح Google Sheets للفريق الهندسي العمل بشكل تعاوني على المحتوى في الوقت الفعلي، مع إمكانية التصدير إلى CSV لاستخدامه في أداة التحويل البرمجي.

## الخطوة 1: إنشاء جدول البيانات

1. افتح Google Sheets: https://sheets.google.com
2. أنشئ جدول بيانات جديد باسم `Civilpedia Content`.
3. أنشئ 8 أوراق (sheets) بالأسماء التالية:
   - `topics`
   - `sections`
   - `blocks`
   - `checklist_items`
   - `table_rows`
   - `accept_reject`
   - `common_mistakes`
   - `equipment_items`

## الخطوة 2: إضافة الرؤوس

1. في كل ورقة، أضف الرؤوس من ملفات `*_template.csv` الموجودة في `docs/content_template/`.
2. الصف الأول من كل ورقة يحتوي على أسماء الأعمدة.
3. الصف الثاني يحتوي على مثال توضيحي (اختياري).
4. من الصف الثالث تبدأ البيانات الفعلية.

## الخطوة 3: تنسيق الخلايا

- اجعل الصف الأول (الرؤوس) **غامقاً** (Bold).
- لا تستخدم الألوان المميزة لأنها لا تصدر إلى CSV.
- لا تدمج الخلايا — ذلك يكسر ترتيب الأعمدة عند التصدير.
- استخدم التعليقات (Comments) لتوثيق ملاحظات المراجعة.

## الخطوة 4: القواعد المهمة

| القاعدة | الشرح |
|---------|-------|
| لا تغير أسماء الأعمدة | يجب أن تبقى بالإنجليزية كما هي في القوالب |
| لا تحذف أي عامود | حتى لو كان فارغاً، يجب بقاء العامود |
| استخدم علامات الاقتباس | إذا كان النص يحتوي على فواصل داخله |
| تاريخ بصيغة ISO | استخدم `YYYY-MM-DDTHH:MM:SS.mmm` |
| TRUE / FALSE | بالأحرف الكبيرة الإنجليزية فقط |

## الخطوة 5: تصدير CSV

1. لكل ورقة على حدة: File → Download → Comma-separated values (.csv)
2. سمِّ الملف حسب اسم الورقة بالضبط.
3. ضع جميع ملفات CSV الثمانية في مجلد واحد.
4. سلم المجلد للمطور لاستخدامه مع أداة التحويل.

## نصائح للعمل الجماعي

- استخدم أذونات التحرير (Edit) لفريق الكتابة فقط.
- اجعل فريق المراجعين والمشرفين بصلاحية التعليق أو العرض (Comment/View).
- عند الانتهاء من موضوع، خذ نسخة منه كاحتياطي.
- استخدم تاريخ التعديل (Revision history) لتتبع التغييرات.
- أضف صف الحالة (Status) لكل موضوع لتوضيح أين هو في سير العمل.

## التحقق من صحة البيانات (Data Validation)

يمكن تفعيل التحقق من صحة البيانات لبعض الأعمدة لتجنب الأخطاء:

1. اختر العمود بالكامل (مثلاً عمود `level`).
2. Data → Data validation → Add rule.
3. حدد النطاق وأضف القواعد التالية:

| العامود | القيم المسموحة |
|---------|----------------|
| `level` | `basic, intermediate, advanced` |
| `status` | `Draft, Engineering Review, Approved, Ready for App` |
| `categoryId` | `concrete, steel, soil, asphalt, general` |
| `isCritical` | `TRUE, FALSE` |
| `reviewRequired` | `TRUE, FALSE` |
| `severity` | `low, medium, high, critical` |
| `text_variant` | `paragraph, note, tip, warning` |
| `safety_severity` | `low, medium, high, critical` |
