# دليل الكاتب — Content Studio

## ما هو Content Studio؟

**Content Studio** هي أداة ويب خفيفة تتيح لك كتابة موضوعات تعليمية ونشرها بصيغة Draft JSON.
تعمل الأداة بالكامل في المتصفح ولا تحتاج إلى تثبيت أي برامج إضافية.

---

## هيكل مجلد Writer Kit

```
Civilpedia_Writer_Kit/
├── index.html                # افتح هذا الملف لبدء Content Studio
├── README_FOR_WRITERS.md     # هذا الدليل
├── css/                      # ملفات التنسيق — لا تعدلها
├── js/                       # ملفات الأداة — لا تعدلها
├── templates/                # قوالب جاهزة للبدء
├── images_to_send_here/      # ضع ملفات الصور هنا قبل الاستخدام
└── completed_drafts/         # احفظ ملفات Draft النهائية هنا قبل الإرسال
```

---

## كيفية البدء

1. **فتح Content Studio**  
   افتح ملف `index.html` في متصفحك (Chrome أو Firefox أو Edge).

2. **تحميل قالب جاهز**  
   - اذهب إلى قائمة "ملف" ← "فتح"  
   - اختر أحد ملفات القوالب من مجلد `templates/`  
   - مثال: `arabic_topic_template.draft.json`

3. **البدء من ملف جديد**  
   يمكنك أيضاً الضغط على "جديد" لإنشاء موضوع فارغ.

---

## كتابة المحتوى بالعربية

- جميع الحقول تدعم الكتابة بالعربية.
- املأ الحقول الإلزامية:
  - **عنوان الموضوع** (titleAr)
  - **التصنيف** (categoryId) — اختر من القائمة المنسدلة
  - **الملخص** (summaryAr) — جملة أو جملتين تصف الموضوع
- أضف وسوم (tags) إن أردت.

---

## إضافة أقسام

- كل موضوع يتكون من **أقسام** (sections).
- لإضافة قسم جديد:
  - اضغط على زر "➕ إضافة بند" في أسفل قائمة الأقسام.
  - اختر نوع القسم (عام، تنفيذي، فحص، سلامة، معدات، مرجع كود).
  - اكتب عنوان القسم بالعربية.

---

## إضافة كتل (Blocks)

كل قسم يحتوي على **كتل** (blocks) — وهي وحدات المحتوى الفردية.

الأنواع المتاحة:

| النوع | الاستخدام |
|-------|-----------|
| نص عادي | فقرات نصية |
| خطوة تنفيذ | خطوة من خطوات العمل |
| ملاحظة سلامة | تنبيه أو ملاحظة سلامة |
| جدول | بيانات جدولية |
| صورة | صور توضيحية |

لكل كتلة زر "✏️ تعديل" يفتح محرراً خاصاً بها.

---

## إضافة الصور

**خطوات إضافة صورة:**

1. أضف كتلة من نوع "صورة".
2. اضغط "✏️ تعديل" على كتلة الصورة.
3. ستظهر شاشة التحرير وفيها:
   - حقل نصي لمسار الصورة
   - زر **"اختيار صورة"** لاختيار ملف من جهازك
4. اضغط **"اختيار صورة"** واختر ملف الصورة من جهازك.
5. سيتم **تعبئة المسار تلقائياً** بالصيغة: `assets/images/اسم_الملف`
6. ستظهر **معاينة** للصورة داخل المحرر.
7. اكتب تعليقاً توضيحياً (اختياري).
8. اضغط **"💾 حفظ"**.

**ملاحظات مهمة عن الصور:**
- الأداة **لا ترفع** الصور إلى أي خادم — المعاينة محلية فقط.
- يجب إرسال ملفات الصورة مع ملف الـ Draft.
- اسم الملف يجب أن يكون **بالإنكليزية** وبدون فراغات.
- يُفضّل استخدام حروف صغيرة (lowercase) وشرطة سفلية `_`.
- مثال على اسم مناسب: `concrete_slump_cone.png`
- مثال على اسم غير مناسب: `اختبار الهبوط.jpeg` أو `Concrete Slump 1.png`

---

## حفظ العمل

- اضغط **"💾 حفظ الكل"** في أعلى أو أسفل الصفحة لحفظ كل التعديلات.
- يمكنك تصدير الملف عبر قائمة "ملف" ← "تصدير".
- احفظ الملف بصيغة `.draft.json`.

---

## تحذيرات مهمة

- ❌ **لا تعدل ملف Draft JSON يدوياً** — استخدم Content Studio فقط.
- ❌ **لا ترسل ملف App-ready JSON** — هذا الملف يُستخدم داخلياً فقط.
- ✅ أرسل فقط ملف Draft JSON + مجلد الصور.

---

## ماذا ترسل بعد الانتهاء؟

**الملفات المطلوبة:**
```
topic_name/
├── topic_name.draft.json       # ملف Draft النهائي
└── images/
    ├── image_1.png             # الصور المستخدمة في الموضوع
    ├── image_2.jpg
    └── ...
```

**مثال:**
```
concrete-slump-test/
├── concrete-slump-test.draft.json
└── images/
    ├── slump_cone.png
    ├── tamping_rod.jpg
    └── slump_measurement.jpg
```

### سير العمل المقترح

1. **ضع صورك** في مجلد `images_to_send_here/` داخل Writer Kit.
2. **افتح Content Studio** واختر صورة باستخدام زر "اختيار صورة" من داخل هذا المجلد.
3. **عند الانتهاء**، احفظ ملف Draft النهائي في مجلد `completed_drafts/`.
4. **جهز الحزمة النهائية**: انسخ ملف Draft من `completed_drafts/` والصور المستخدمة من `images_to_send_here/` وضعها في مجلد واحد باسم الموضوع.

> 💡 نصيحة: استخدم مجلد `images_to_send_here/` كمساحة عمل — ضع جميع صورك هناك قبل البدء، ثم اخترها عبر الأداة. هذا يضمن تطابق المسارات.

---

## قواعد تسمية الصور

- استخدم **أحرف إنكليزية** فقط (a-z, A-Z, 0-9)
- لا تستخدم فراغات — استخدم شرطة سفلية `_` بدلاً منها
- يُفضّل الأحرف الصغيرة (lowercase)
- اجعل الاسم واضحاً ومرتبطاً بمحتوى الصورة

**أمثلة جيدة:**
```
concrete_slump_cone.png
concrete_cube_samples.jpg
rebar_cover_spacer.jpg
curing_water_hose.png
```

**أمثلة غير صحيحة:**
```
صورة 1.jpeg              ← يحتوي على عربية وفراغات
Concrete Slump Cone.png  ← يحتوي على فراغات
test (2).jpg             ← يحتوي على فراغات وأقواس
```

---

## قائمة الفحص قبل الإرسال

تأكد من النقاط التالية قبل إرسال ملفاتك:

- [ ] ملف Draft يفتح بشكل صحيح في Content Studio
- [ ] جميع الحقول الإلزامية مملوءة (عنوان، تصنيف، ملخص)
- [ ] الصور تم اختيارها باستخدام زر "اختيار صورة"
- [ ] التعليقات التوضيحية للصور مكتوبة (اختياري لكن مفضل)
- [ ] جميع الصور موجودة في مجلد `images/`
- [ ] اسم ملف الصورة مطابق للمسار الظاهر في الحقل النصي
- [ ] أداة التحقق من الصحة لا تظهر أخطاء (اضغط "تحقق من الصحة" في Content Studio)
- [ ] لا توجد أخطاء حمراء في لوحة التحقق
- [ ] تم حفظ العمل النهائي كملف `.draft.json`
